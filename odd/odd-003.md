# ODD-003: Estructura base de la parte visual con Angular y Tailwind CSS

## Objetivo

Crear la estructura inicial de la parte visual del sistema SIFE en la carpeta `partevisual`, utilizando Angular 22 y Tailwind CSS 4, con rutas basadas en almohadilla (`#`), un archivo común para componentes reutilizables y una pantalla de trabajo compuesta por barra superior, barra lateral y área de trabajo con migas de pan. Todos los botones deben incluir iconos.

## Contexto

Las ODD-001 y ODD-002 dejaron disponibles la estructura base de la parte lógica y de la base de datos. El siguiente paso es construir la base del frontend con una interfaz consistente y reutilizable. Se utilizará Angular 22 con componentes standalone, Tailwind CSS 4 para los estilos, rutas con `withHashLocation()` para evitar configuraciones adicionales en el servidor y una organización por capas que separe el layout, los componentes compartidos y las páginas.

## Comprende

- Creación del proyecto `partevisual` con Angular 22.
- Configuración de Tailwind CSS 4.
- Configuración de rutas con almohadilla (`#`) mediante `withHashLocation()`.
- Creación del archivo común `comun.ts` con los componentes reutilizables.
- Construcción de la pantalla de trabajo con tres elementos:
  - **Barra superior:** botón para mostrar u ocultar la barra lateral y botón para maximizar el área de trabajo.
  - **Barra lateral:** menú de navegación.
  - **Área de trabajo:** siempre visible con migas de pan y el contenido de la ruta.
- Uso de iconos en todos los botones.
- Manejo del estado del layout mediante señales de Angular.
- Diseño adaptable a pantallas pequeñas.

No comprende: autenticación, integración con la API, pantallas funcionales de módulos, formularios, pruebas de extremo a extremo ni despliegue.

Configuración de rutas con almohadilla:

```ts
import { Routes } from '@angular/router';

export const rutas: Routes = [
  { path: '', pathMatch: 'full', redirectTo: 'inicio' },
  {
    path: 'inicio',
    loadComponent: () => import('./paginas/inicio').then((modulo) => modulo.Inicio),
    data: { miga: 'Inicio' }
  },
  { path: '**', redirectTo: 'inicio' }
];
```

```ts
import { ApplicationConfig } from '@angular/core';
import { provideRouter, withHashLocation } from '@angular/router';
import { rutas } from './app.routes';

export const configuracionAplicacion: ApplicationConfig = {
  providers: [
    provideRouter(rutas, withHashLocation())
  ]
};
```

## Implementación

1. **Crear el proyecto** con Angular CLI 22:

   ```bash
   npx @angular/cli@22 new partevisual --routing --style=css --skip-git
   ```

2. **Instalar Tailwind CSS 4**:

   ```bash
   npm install -D tailwindcss @tailwindcss/postcss postcss
   ```

3. **Configurar PostCSS** en `.postcssrc.json`:

   ```json
   {
     "plugins": {
       "@tailwindcss/postcss": {}
     }
   }
   ```

4. **Importar Tailwind** en `src/styles.css`:

   ```css
   @import "tailwindcss";
   ```

5. **Instalar la librería de iconos**:

   ```bash
   npm install lucide-angular
   ```

6. **Configurar las rutas con almohadilla** en `app.config.ts` usando `withHashLocation()`, de modo que las direcciones queden como `http://localhost:4200/#/inicio`.

7. **Crear el componente `Icono`** como envoltorio de la librería de iconos, con entradas para nombre, tamaño y clase. Todos los iconos de la aplicación deben pasar por este componente.

8. **Crear el componente `BotonIcono`** con las entradas `icono`, `etiqueta`, `titulo` y `tipo`, y la salida `accion`. Debe renderizar siempre un icono y usar `aria-label` y `title` cuando no tenga texto visible.

9. **Crear el componente `MigasPan`** que escuche los eventos de navegación, construya la ruta actual y muestre las migas de pan a partir de la propiedad `data.miga` de cada ruta.

10. **Crear el servicio `EstadoLayoutServicio`** con señales para `barraLateralVisible` y `pantallaCompleta`, y los métodos `alternarBarraLateral()` y `alternarPantallaCompleta()`.

11. **Crear el componente `BarraSuperior`** con:
    - Botón para mostrar u ocultar la barra lateral (iconos `PanelLeftClose` y `PanelLeftOpen`).
    - Botón para maximizar o restaurar el área de trabajo (iconos `Maximize2` y `Minimize2`).
    - Título de la aplicación.

12. **Crear el componente `BarraLateral`** con el menú de navegación. Cada opción debe tener icono, texto y `routerLink`, y debe resaltarse con `routerLinkActive`. Debe ocultarse o mostrarse según `barraLateralVisible`.

13. **Crear el componente `AreaTrabajo`** que contenga siempre las migas de pan y el `router-outlet`. El botón de maximizar debe ampliar esta área a pantalla completa.

14. **Crear el componente `App`** como contenedor del layout, con la barra superior, la barra lateral y el área de trabajo.

15. **Crear la página `Inicio`** con `data: { miga: 'Inicio' }` para validar la navegación y las migas de pan.

16. **Aplicar Tailwind CSS** para el diseño, el espaciado, la tipografía, los colores y el comportamiento adaptable.

17. **Verificar** que todos los botones tengan icono y etiqueta accesible.

## Verificación

1. Instalar dependencias y compilar:

   ```bash
   cd partevisual
   npm install
   npm run build
   ```

2. Iniciar la aplicación:

   ```bash
   npm run start
   ```

3. Abrir la aplicación y confirmar la ruta con almohadilla:

   ```text
   http://localhost:4200/#/inicio
   ```

4. Verificar la barra superior:
   - El botón de la barra lateral muestra y oculta la barra lateral.
   - El botón de maximizar amplía y restaura el área de trabajo.
   - Ambos botones muestran icono.

5. Verificar la barra lateral:
   - El menú muestra las opciones con icono y texto.
   - La opción activa se resalta correctamente.

6. Verificar el área de trabajo:
   - Las migas de pan se muestran siempre.
   - El contenido de la ruta se carga en el `router-outlet`.

7. Recargar la página en `/#/inicio` y confirmar que la ruta se mantiene.

8. Revisar que ningún botón carezca de icono y que los botones sin texto tengan etiqueta accesible.
