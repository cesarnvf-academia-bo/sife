# ODD-002: Estructura inicial de la base de datos

## Objetivo

Crear la estructura inicial de la base de datos del sistema SIFE en la carpeta `basededatos`, mediante tres archivos: `tablas.sql`, `datos.sql` e `inicializar.sh`. El script de inicialización debe eliminar la base de datos existente, crearla nuevamente y cargar la estructura y los datos iniciales.

## Contexto

La ODD-001 dejó disponible la estructura base de la parte lógica en `partelogica`. El siguiente paso es contar con una base de datos reproducible y versionada que permita iniciar el desarrollo de los módulos funcionales. Se utilizará PostgreSQL, disponible en el entorno, y se mantendrá una nomenclatura en español y código limpio.

## Comprende

- Creación de la carpeta `basededatos`.
- Creación del archivo `tablas.sql` con la tabla `empresa`.
- Creación del archivo `datos.sql`, vacío por el momento.
- Creación del archivo `inicializar.sh` que:
  - Elimina la base de datos si existe.
  - Crea la base de datos.
  - Carga `tablas.sql`.
  - Carga `datos.sql`.
- Uso de PostgreSQL como motor de base de datos.

No comprende: tablas de otros módulos, migraciones automáticas, datos de prueba, usuarios o permisos de base de datos, respaldos ni despliegue.

## Entregable

Estructura propuesta:

```text
basededatos/
├── tablas.sql
├── datos.sql
└── inicializar.sh
```

Tabla `empresa` con las siguientes columnas:

| Columna | Tipo |
| --- | --- |
| `id` | `BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY` |
| `nit` | `VARCHAR(20)` |
| `razonsocial` | `VARCHAR(250)` |
| `codigoSistema` | `VARCHAR(50)` |
| `modalidad` | `VARCHAR(50)` |
| `ambiente` | `VARCHAR(50)` |
| `rutacodigo` | `TEXT` |
| `rutasincronizacion` | `TEXT` |
| `rutaoperacion` | `TEXT` |
| `rutacompraventa` | `TEXT` |
| `token` | `TEXT` |
| `rutafirmadigital` | `TEXT` |
| `clavefirmadigital` | `TEXT` |

Contenido de referencia de `tablas.sql`:

```sql
CREATE TABLE empresa (
    id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    nit VARCHAR(20),
    razonsocial VARCHAR(250),
    "codigoSistema" VARCHAR(50),
    modalidad VARCHAR(50),
    ambiente VARCHAR(50),
    "rutacodigo" TEXT,
    "rutasincronizacion" TEXT,
    "rutaoperacion" TEXT,
    "rutacompraventa" TEXT,
    token TEXT,
    "rutafirmadigital" TEXT,
    "clavefirmadigital" TEXT
);
```

`datos.sql` debe existir como archivo vacío.

Contenido de referencia de `inicializar.sh`:

```bash
#!/usr/bin/env bash
set -euo pipefail

NOMBRE_BASE_DATOS="${NOMBRE_BASE_DATOS:-sife}"
USUARIO_BASE_DATOS="${USUARIO_BASE_DATOS:-postgres}"
DIRECTORIO_SCRIPT="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"

dropdb --if-exists --force --username "$USUARIO_BASE_DATOS" "$NOMBRE_BASE_DATOS"
createdb --username "$USUARIO_BASE_DATOS" "$NOMBRE_BASE_DATOS"
psql --username "$USUARIO_BASE_DATOS" --dbname "$NOMBRE_BASE_DATOS" --file "$DIRECTORIO_SCRIPT/tablas.sql"
psql --username "$USUARIO_BASE_DATOS" --dbname "$NOMBRE_BASE_DATOS" --file "$DIRECTORIO_SCRIPT/datos.sql"
```

## Implementación

1. Crear la carpeta `basededatos` en la raíz del proyecto.
2. Crear `tablas.sql` con la tabla `empresa` y las columnas definidas.
3. Crear `datos.sql` como archivo vacío.
4. Crear `inicializar.sh` con permisos de ejecución.
5. Parametrizar el nombre de la base de datos y el usuario mediante variables de entorno con valores por defecto.
6. Asegurar que el script elimine la base de datos existente, la cree y cargue ambos archivos SQL en orden.
7. Respetar las variables estándar de PostgreSQL (`PGHOST`, `PGPORT`, `PGUSER`, `PGPASSWORD`) para la conexión.
8. Mantener nombres de archivos, variables y mensajes en español.
9. Ejecutar el script y validar la estructura creada.

## Criterios de Aceptación

- [ ] Existe la carpeta `basededatos`.
- [ ] Existe el archivo `tablas.sql`.
- [ ] Existe el archivo `datos.sql` y se encuentra vacío.
- [ ] Existe el archivo `inicializar.sh` y es ejecutable.
- [ ] `inicializar.sh` elimina la base de datos si existe.
- [ ] `inicializar.sh` crea la base de datos.
- [ ] `inicializar.sh` carga `tablas.sql`.
- [ ] `inicializar.sh` carga `datos.sql`.
- [ ] La tabla `empresa` contiene todas las columnas definidas.
- [ ] El script puede ejecutarse más de una vez sin errores.

## Verificación

1. Ejecutar el script de inicialización:

   ```bash
   bash basededatos/inicializar.sh
   ```

2. Verificar la estructura de la tabla:

   ```bash
   psql --dbname sife --command '\d empresa'
   ```

3. Verificar que la tabla no contiene registros:

   ```bash
   psql --dbname sife --tuples-only --no-align --command 'SELECT COUNT(*) FROM empresa;'
   ```

   El resultado debe ser `0`.

4. Ejecutar nuevamente el script para confirmar que la base de datos se recrea correctamente:

   ```bash
   bash basededatos/inicializar.sh
   ```

5. Confirmar que no se generan errores en ninguno de los pasos.

## Confirmación y cierre

La ODD se considera completada cuando:

- Todos los criterios de aceptación están marcados como cumplidos.
- El script `inicializar.sh` se ejecuta correctamente y recrea la base de datos.
- La tabla `empresa` existe con las columnas definidas.
- `datos.sql` permanece vacío.
- Se deja constancia de las evidencias de ejecución y verificación.
- El responsable técnico revisa y aprueba el entregable, dejando constancia del cierre de la ODD-002.
